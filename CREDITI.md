# Crediti e risorse

**Total Rush:** personaggi cartooneschi, rig, firma, icone, simboli delle squadre, arena, interfaccia e suoni sintetizzati originali del progetto.

**Animazioni:** locomozione Quaternius Universal Animation Library Standard, CC0. Calcio adattato da animazioni Meshy già autorizzate, retargettate sui nuovi personaggi. Attribuzione: Tommaso / Meshy AI — “Model rigged/animated with Meshy”, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

**Font:** Barlow, Jeremy Tribby / Barlow Project; Liberation Sans. SIL Open Font License. Testi delle licenze inclusi nell’app.

**Motore:** Unity 6.6, Universal Render Pipeline, Input System, Cinemachine, uGUI e TextMeshPro. Mantengono le rispettive licenze.

La soundtrack e le copertine personali non vengono distribuite. Nessun asset o personaggio Nintendo incluso. Il repository contiene pacchetti compilati e documentazione per i giocatori; non contiene i sorgenti Unity o Blender.
